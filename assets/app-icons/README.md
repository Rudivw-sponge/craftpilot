# App icons

The 64×64 app icons of the ArtCraft creative apps, shown on the app chips in the CraftPilot
panel. Each file is copied unchanged from its app's repository, at
`assets/app-icon/hicolor/64x64/apps/ai.storyteller.<app>.png`.

| File | Source repository | Licence text |
|---|---|---|
| `photocraft.png` | [storytold/photocraft](https://github.com/storytold/photocraft) | `LICENSE-MIT-photocraft.txt` |
| `vectorcraft.png` | [storytold/vectorcraft](https://github.com/storytold/vectorcraft) | `LICENSE-MIT-vectorcraft.txt` |
| `designcraft.png` | [storytold/designcraft](https://github.com/storytold/designcraft) | `LICENSE-MIT-designcraft.txt` |
| `effectcraft.png` | [storytold/effectcraft](https://github.com/storytold/effectcraft) | `LICENSE-MIT-effectcraft.txt` |
| `filmcraft.png` | [storytold/filmcraft](https://github.com/storytold/filmcraft) | `LICENSE-MIT-filmcraft.txt` |
| `lightcraft.png` | [storytold/lightcraft](https://github.com/storytold/lightcraft) | `LICENSE-MIT-lightcraft.txt` |
| `pdfcraft.png` | [storytold/pdfcraft](https://github.com/storytold/pdfcraft) | `LICENSE-MIT-pdfcraft.txt` |

Each app's icon licence (`LICENSE-<app>.txt`, copied from the same folder) lets you use the
icon under the MIT licence or Apache-2.0, at your option. CraftPilot uses it under the MIT
licence, and the full text, with its copyright notice, is in `LICENSE-MIT-<app>.txt`.

These are the per-app icons only. The ArtCraft name, wordmark and mark are trademarks under
separate, restrictive terms (`docs/brand/LICENSE-brand.txt` in each app repository), so they
are not used in this project.
